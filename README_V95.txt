DREAMFOREN v95 - 업체현황/일정 온라인 연동 보강

변경사항
1) 업체현황 통합검색 개선
   - 업체명, 소재지, 사업자번호, 대표자, 환경기술인, 연락처, 이메일, 업종
   - 공백/하이픈/괄호/기호 차이 무시
2) 시설별 측정항목
   - + 항목 추가를 계속 사용할 수 있는 동적 배열 구조 유지/확인 (고정 3개 제한 없음)
3) 일정관리 Supabase 영구저장
   - 신규 일정 저장
   - 예정/확정 변경
   - 측정완료/완료취소
   - 일정 삭제 상태
   를 schedules 테이블에 저장
4) 측정완료/완료취소 시 업체·시설 measurement_history 동기화 후 업체현황 즉시 재계산
5) 계약관리/네비게이션은 v94 동작을 유지하며 수정하지 않음

테스트 순서
- 업체현황 검색
- 시설 항목 4개 이상 추가 후 저장/재열기
- 일정 하나 선택 -> 측정완료 -> 업체현황 상태 확인
- 완료취소 -> 업체현황 원복 확인
- 이후 시료채취기록 테스트
