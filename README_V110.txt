DREAMFOREN v110 - 직원관리

추가 기능
- 관리자 전용 '직원관리' 메뉴
- 신규 가입자 승인대기 건수 배지
- 직원별 승인 / 사용중지
- 권한: 직원(staff) / 관리자(admin)
- 소속: 관리 / 사무실 / 1팀 / 2팀 / LAB / 미지정
- 현재 로그인한 관리자 본인은 관리자 해제/사용중지 방지
- 신규 가입자 이메일을 profiles.email에 저장

필수 1회 작업
1) Supabase SQL Editor에서 03_v110_employee_management.sql 전체 실행
2) GitHub management 저장소에 v110 웹 파일 업로드/덮어쓰기
3) Commit changes 후 GitHub Pages 반영 대기
4) Ctrl+F5 후 관리자 로그인 -> 직원관리 확인
