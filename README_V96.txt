DREAMFOREN v96 - 일정 단순화 / 업체상태 연결

1. 일정등록에서 시설/측정항목 선택 제거
2. 일정은 업체 + 날짜 + 담당자 + 구분 + 일정내용 + 비고 + 상태만 저장
3. 일정 완료/완료취소는 업체현황 상태만 변경하며 시설 measurement_history는 수정하지 않음
4. 업체 시설 비고에 '고장', '미측정', '보류', '추후', '확인' 등이 있으면 일정 완료보다 우선하여 '측정확인필요'
5. 온라인 schedules를 새로고침 시 다시 불러와 일정이 사라지지 않도록 보완
6. Supabase RLS로 일정 저장이 막히는 경우를 위해 01_schedule_sync_rls.sql 포함
7. 계약관리/네비게이션/시료채취 로직은 변경하지 않음
